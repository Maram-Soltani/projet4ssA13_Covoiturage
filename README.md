
# Projet Covoiturage

## Présentation
Plateforme web de covoiturage permettant de mettre en relation les conducteurs et les passagers afin de partager leurs trajets.

## Technologies utilisées
- Backend : Java, Spring Boot
- Frontend : Angular
- Architecture : Microservices

## Architecture du projet
- Backend : Regroupe les microservices métier.
- Frontend : Application cliente Angular.
- Documentation : Présentations, diagrammes et dossier technique.

## Microservices
1. Utilisateur
2. Trajet
3. Réservation
4. Véhicule
5. Message
6. Réclamation
